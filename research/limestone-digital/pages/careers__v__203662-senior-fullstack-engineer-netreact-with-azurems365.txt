About the Project
The scope of the project is the delivery of a work order management application for the Client’s aircraft maintenance (CAMO) department, built as an extension of the company-wide SharePoint intranet. The application replaces a manual, document-based process. It holds aircraft, maintenance facility, contract and warranty data in a central database, generates work order documents from that data, and tracks every work order through its lifecycle. The platform runs entirely on the Microsoft 365 and Azure ecosystem the Client already operates. That means Azure SQL for structured data, SharePoint Online for documents and hosting, SPFx web parts for the user interface, and Azure Functions with the Microsoft Graph API for backend logic, integrations and document generation.
The engineer hired into this role will own the backend and data side of the solution end-to-end.
