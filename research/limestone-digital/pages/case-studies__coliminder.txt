IoT Water Quality Monitoring Platform
ColiMinder is an IoT solution for water quality monitoring and reflecting probing results in real-time.
IoT
Managed Delivery
Industries
Environmental Technology, Water Quality Monitoring
Platform
Web application for desktop
Delivery scope
Embedded system integration, High-load backend engineering, Real-time data processing, UI/UX design, QA & field testing
ABOUT THE PROJECT
Project overview
Project Duration:
7 Months
Team size
3
Core technologies
MongoDB, AngularJS +
ColiMinder faced growing operational complexity due to large volumes of microbiological sensor data and limited ability to process results in real time.
Limestone Digital was engaged to build a centralized web platform that could process telemetry data, support real-time analytics, and transform ColiMinder’s hardware system into a market-ready solution
Challenge
When starting the project, the team faced several operational challenges:
Processing large volumes of raw telemetry data updated every few seconds
Interpreting complex machine-level data that required R&D involvement
Limited ability to provide real-time monitoring results
High dependency on manual data processing
What we do
Solution
Limestone Digital redesigned the platform architecture and introduced structured data processing workflows.
The solution enabled real-time data collection, centralized device management, and scalable analytics, allowing ColiMinder to operate efficiently across a distributed network of devices.
SYSTEM ARCHITECTURE
Comprehensive scalable platform
The system architecture was designed to support scalable data ingestion, real-time processing, and reliable analytics across distributed IoT devices.
Platforms features
Geolocation
Provides real-time visibility into device locations and operational status, helping teams quickly identify issues and respond to water quality incidents
Device management
Enables centralized configuration, monitoring, and maintenance of connected devices across the ColiMinder network.
Pod spec
Data processing & analytics
Processes high-frequency sensor data into real-time analytics, enabling monitoring of microbiological parameters and trend analysis.
Comprehensive analytics – the app analyzes more than 40 parameters and measurements for each ColiMinder’s work phase.
Real-time data visualization – all charts are created in live mode, which allows users to monitor water conditions and make informed decisions in real-time.
Pre-set filters – we’ve created 10 pre-set data filters that speed up onboarding of new customers. Although ColiMinder users can build their own view filters if needed.
A role-based access control system
Supports role-based access control, allowing organizations to manage permissions and data visibility across teams.
Notification Center
Notification Center
Delivers automated alerts based on system events and telemetry data, ensuring timely response to critical issues.
Help center
Provides centralized access to documentation and training materials to support efficient system operation.
Impact & Results
As a result, ColiMinder received a scalable web platform that automated data processing, reduced manual operational effort, and enabled real-time water quality monitoring.
This allowed the client to successfully bring the solution to market and operate it at scale.
